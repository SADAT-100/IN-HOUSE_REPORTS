# Extra Channel Portal

Reporting portal for the In House store on the Extra marketplace: sales, orders, products, payouts, commission and fees, returns, and delivery.

Open `index.html` in a browser. The orders export and transaction log (19 Apr to 12 Oct 2026) are built into the page. To refresh the numbers, open **Update data** and drop in the latest Extra orders export (.xlsx) and transaction log (.csv).

- `index.html`: the portal, with data and profile photo embedded
- `profile.jpg`: the cropped profile photo
