# Extra Channel Portal

Reporting portal for the In House store on the Extra marketplace: sales, orders, products, payouts, commission and fees, returns, and delivery.

Open `index.html` in a browser. The orders export and transaction log (19 Apr to 12 Oct 2026) are built into the page. This copy is view-only.

Updates are published from the claude.ai version of the portal, where only the owner sees the upload controls. Before publishing, the page keeps only the columns the reports use, so customer names, phones, emails and addresses never reach the published page.
